      Pour les applis utilisées en magasin (Pour être dans le vert, Suivi magasin, Kaizen) : un code à 6 chiffres par magasin, envoyé par mail sur la boîte du magasin et saisi une seule fois par poste. Régénérer un code déconnecte les postes du magasin.
